## Security and reuse review

The inspected upstream scripts perform filesystem writes, subprocess calls, API requests, formatting, metadata verification, and arXiv retrieval. None was executed or copied. This skill's two scripts were implemented independently with the Python standard library, accept only explicit local paths, avoid shell execution and network calls, and are covered by local tests.

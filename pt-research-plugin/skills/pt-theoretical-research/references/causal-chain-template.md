# Causal-chain template

## Essence

- **Status:** `well_supported | provisional | competing_hypotheses | unresolved`
- **Statement:** one to three sentences naming source, coupling, controlling response, and amplification/suppression/selection.
- **Mechanistic necessity test:** what changes if the central mechanism is removed?
- **Evidence and caveats:**

## Whole-chain hypothesis

```text
controlled input / energy source
→ physical coupling or transduction
→ internal state or field evolution
→ amplification, suppression, instability, or modal selection
→ observable-generating process
→ measured observable
```

## Apparatus branches

For each branch, state the triggering ambiguity, changed links, changed essence if any, and evidence needed to choose the branch.

## Component interfaces

```text
[component A] → [quantity, unit, coordinates/domain] → [component B]
```

Record sign/coordinate convention, temporal or frequency representation, linearity, geometry/material overlap, and boundary-condition compatibility at every interface.
